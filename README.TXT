MAZE - CYBERPUNK 3D RAYCASTING GAME
====================================

WHAT IS THIS?
-------------
MAZE.EXE is a 3D first-person maze game for MS-DOS.
Navigate through 3 cyberpunk mazes using raycasting graphics.

SYSTEM REQUIREMENTS
-------------------
* 386+ CPU
* VGA graphics
* MS-DOS 3.3+
* 512 KB RAM
* Sound Blaster (optional)

INSTALLATION
------------
1. Copy files from CD to hard drive
2. Run MAZE.EXE
3. Follow prompts

CONTROLS
--------
UP ARROW    - Move forward
DOWN ARROW  - Move backward  
LEFT ARROW  - Rotate left
RIGHT ARROW - Rotate right
ESC         - Exit game

FEATURES
--------
* 3D raycasting engine
* 3 difficulty levels
* Textured walls and floors
* Real-time timer
* Sound Blaster audio
* Double-buffered graphics

THE 3 LEVELS
------------
LEVEL 1: Easy - bright neon theme
LEVEL 2: Moderate - darker atmosphere
LEVEL 3: Extreme - very challenging

QUICK START
-----------
1. Run MAZE.EXE
2. Press any key at splash screen
3. Use arrow keys to navigate
4. Find exit at bottom-center
5. Complete all 3 levels
